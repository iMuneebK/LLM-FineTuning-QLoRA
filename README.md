## Description
This project focuses on llm fine-tuning. It aims to provide a robust, efficient, and scalable solution using modern technologies and best practices in the field.

## Key Features
- High performance architecture
- Extensible and modular design
- Comprehensive data processing capabilities
- Easy-to-use interface and quick setup

## Tech Stack
- PEFT\n- QLoRA\n- BitsAndBytes\n- HuggingFace\n- PyTorch

## Quick Start
```bash
git clone https://github.com/iMuneebK/LLM-FineTuning-QLoRA.git
cd LLM-FineTuning-QLoRA
pip install -r requirements.txt
python main.py
```
